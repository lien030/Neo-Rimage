## Changes / 本轮改动

- Patch the vendored zune-farbfeld 0.5.2 decoder for byte/sample sizing, checked dimensions and repeated header reads. Original licenses and patch provenance are retained.
- Keep WebP quality editable in both modes; lossless mode labels it compression effort without changing the existing parameter or defaults.
- Read every 200-item detail page, retain partial results on query failure, and ignore responses after close, refresh or task changes.
- Clear confirmed batches of removable terminal tasks, continue after individual failures, retry failed records, and refresh authoritative snapshots through the highest acknowledged revision.
- Use the failed count as the error-details button. Shorten the cleanup menu, align counts, improve parameter card sizing and accessible names, and synchronize English, Chinese and Japanese text.

修复 Farbfeld 解码，开放 WebP 无损压缩强度编辑，补齐分页错误详情及任务清理，并改善失败入口、菜单、长标签和键盘可访问性。保留现有 IPC 接口、总体布局、默认参数和运行时依赖。

## Image and window regressions / 图片与窗口回归

- The repair matrix covers 184 encoding/boundary scenarios and 42 roundtrip scenarios: 217 successful outputs and 9 expected input/parameter rejections, with no unexpected failure.
- All 17 previously failing Farbfeld outputs and an independent 1×1 input are readable. Independent RGBA16 tests verify endianness, alpha, sample precision, exact/undersized/oversized buffers, repeated headers, truncation, dimension overflow and PNG→FF→PNG sample equality.
- WebP lossless output with near-lossless disabled and transparent RGB retained preserves pixels at effort 1, 75 and 100. Empty and out-of-range form values remain editable and are rejected clearly.
- Pillow independently decodes 137 supported outputs without decode or dimension errors. Its unsupported FF/JXL/PAM outputs are covered by native roundtrip checks.
- Pagination tests cover an error on the second page and at item 1001, request failure, and late responses. Cleanup tests cover mixed states, repeated invocation, partial failure, changed states, retry and refresh failure.
- Actual 800×600 Windows UI checks cover all three languages, a 201-item batch with its last item failing, path wrapping, internal scrolling, expandable diagnostics and keyboard focus restoration. Japanese maximized-window checks cover the table and parameter cards. The revised clickable failed text and compact Chinese cleanup menu are also checked at 800×600.
- Clearing test task records preserves input and output images. GUI fixtures are delivered through real Tauri drag-drop events by a test harness; this substitutes only OS drag delivery, not scanning, IPC or conversion.

修复阶段的 226 个矩阵场景符合预期；真实窗口验证包括三语错误详情、第二页失败、滚动与焦点返回、活动任务保留和图片文件保留。最大化人工检查使用日文；800×600 覆盖中英日文。

## Distribution boundary / 发行验证边界

Windows x64 is the distribution target. NSIS, MSI and the portable ZIP use the same release executable; the portable ZIP includes every configured license/source resource and SHA256SUMS covers all three packages. Packages are unsigned and require WebView2.

The optimized v0.2.0 application, NSIS installer and MSI package build successfully. EXE product/file versions are both 0.2.0. ZIP integrity and the SHA-256 hashes are checked; its executable and all seven configured resources match the build outputs. On the development host, the release application starts with its backend ready and the creation form loads all ten encoders.

Clean-Windows startup/conversion and installation/uninstallation are not verified. macOS/Linux packages and other DPI configurations are not covered. Existing EXIF automatic orientation and lossy AVIF alpha limitations are unchanged. The existing Vite chunk-size and ts-rs attribute messages are recorded as build notes, not test failures.

发行目标为 Windows x64。优化发行程序、NSIS 和 MSI 均构建成功；EXE 版本为 0.2.0。便携 ZIP 与三个发行包的 SHA-256 已核对，包内 EXE 和七个资源文件与构建输出一致。开发机上发行程序启动正常，后端就绪，创建表单载入全部十个编码器。未验证干净 Windows 的启动、转换及安装/卸载，未验证 macOS/Linux 或其他 DPI。EXIF 自动旋转和有损 AVIF 透明度限制仍按原范围保留。
